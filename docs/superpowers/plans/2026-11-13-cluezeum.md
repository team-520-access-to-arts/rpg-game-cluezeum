# Cluezeum Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish the approved five-work museum RPG as a static GitHub Pages app.
**Architecture:** Typed bundled content and a pure game state machine feed a responsive React handheld. A compact validated cookie holds progress; no backend is used.
**Tech Stack:** React, TypeScript, Vite, Vitest, Playwright, GitHub Pages.
**Spec:** ../specs/2026-11-13-cluezeum-design.md

## Global Constraints
- Five verified MoMA works; virtual exhibition, not a claim all five are on view.
- Four roles, twenty distinct missions, five stops per playthrough, eight endings.
- Three shape-labeled buttons, keyboard access, 320px minimum viewport.
- Cookies under 4 KB, 30-day lifetime, project-scoped path, no personal data.
- No backend, database, accounts, or API credentials.

## Review Focus
- A corrupted cookie must never create an impossible route or crash rendering.
- Fast repeated input must not skip stops or duplicate clues.
- Unsupported speech and blocked cookies must not stop gameplay.
- Asset paths must work under the repository's GitHub Pages subpath.
- Artwork details must remain observable on mobile and at larger text sizes.
